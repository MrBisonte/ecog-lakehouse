# ADR-0005: NWB input and export through an optional dependency

| | |
|---|---|
| Status | proposed |
| Date | 2026-09-21 |
| Deciders | Alexandre Monteiro |
| Supersedes | none |
| Superseded by | |

## Context

Neurodata Without Borders (NWB) is the HDF5 based exchange format neuroscience archives such as DANDI expect. The spec names an NWB adapter on the roadmap of section 2 and an export in section 3.4. Reading and writing NWB in Python means `pynwb`, which brings `h5py` and `hdmf`. The runtime dependencies of this system are `duckdb`, `scipy` and `pyyaml` by decision, and a new one needs an ADR. The same `h5py` would also read MATLAB v7.3 files, which are HDF5.

## Options considered

| Option | Summary | Rejected because |
|---|---|---|
| Write NWB by hand with `h5py` | One dependency instead of three | The NWB schema is versioned and validated; a hand written file drifts from it and DANDI rejects it |
| Export through a separate tool outside this repo | No dependency here | The export is a governed dataset, its lineage identifiers and evidence belong in the same build |
| `pynwb` as an optional extra, `pip install -e ".[nwb]"`, adapter and export skipped with a printed reason when it is missing | `make all` stays on three dependencies; an install with the extra gains the adapter and the export | proposed |

## Decision

Proposed, not taken. If accepted: `pynwb` goes under `[project.optional-dependencies] nwb` in `pyproject.toml`, `pipeline/convert_mat.py` registers an `nwb` adapter only when the import succeeds, and `pipeline/export_nwb.py` writes one NWB file per Silver record set with the `lid` of each record in the file's identifier field. No file under `docs/data/` is NWB.

## Consequences

Until accepted, nothing in the pipeline imports `pynwb`, and a MATLAB v7.3 source file is skipped with a printed reason rather than read through `h5py`.
